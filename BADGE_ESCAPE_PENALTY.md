# Механика штрафа при срыве Значка Рыболова

## Описание

Когда игрок ловит **Значок Рыболова** (fisherman_badge), но рыба срывается во время подтягивания, игрок получает **штраф** - прогресс откатывается назад на случайное число.

## Как это работает

### Условия активации
Штраф применяется только когда:
1. Игрок зацепил Значок Рыболова (currentLoot = fisherman_badge)
2. Рыба сорвалась (gameState переходит в ESCAPED)
3. Это может произойти если:
   - Натяжение лески достигло 100% (перетянули)
   - Натяжение упало до 0% (слишком слабо тянули)

### Размер штрафа
- **Минимум:** 5 пойманных рыб
- **Максимум:** 15 пойманных рыб
- **Случайный выбор:** каждый раз разное значение в этом диапазоне

### Пример

```
Текущий прогресс: 45/50
↓
Зацепил Значок Рыболова!
↓
Перетянул леску... СОРВАЛСЯ!
↓
Штраф: -12 рыб
↓
Новый прогресс: 33/50
```

## Настройка

Диапазон штрафа можно изменить в `src/lib/fishing/constants.ts`:

```typescript
export const BADGE_ESCAPE_PENALTY_MIN = 5;  // Минимальный штраф
export const BADGE_ESCAPE_PENALTY_MAX = 15; // Максимальный штраф
```

## Логирование

При срыве бейджа в консоли появится:

```
💨 Fish escaped!
😱 FISHERMAN BADGE ESCAPED! Progress penalty: -12 (45 → 33)
💾 Saving player data: {catchesWithoutBadge: 33, ...}
```

## Стратегия игры

### Риск vs Награда
- При приближении к порогу (45-50 рыб) бейдж может выпасть **случайно**
- Если вы не уверены в своих силах - можно **специально** упустить обычную рыбу
- Если сорвете бейдж - потеряете значительный прогресс!

### Рекомендации
1. **Тренируйтесь** на обычной рыбе перед тем как ловить бейдж
2. **Следите за натяжением** - держите его в зеленой/желтой зоне
3. **Не спешите** - лучше медленно, но верно
4. **Будьте готовы** - при прогрессе 45+ бейдж может выпасть в любой момент

## Технические детали

### Предотвращение отрицательного прогресса
```typescript
const newProgress = Math.max(0, pd.catchesWithoutBadge - penalty);
```
Прогресс не может стать отрицательным - минимум 0.

### Определение диапазона
```typescript
const range = BADGE_ESCAPE_PENALTY_MAX - BADGE_ESCAPE_PENALTY_MIN + 1;
const penalty = Math.floor(Math.random() * range) + BADGE_ESCAPE_PENALTY_MIN;
```

## Баланс

Эта механика добавляет:
- ✅ **Напряжение** - каждый улов бейджа важен
- ✅ **Риск** - можно потерять много прогресса
- ✅ **Награду за скилл** - умелые игроки теряют меньше прогресса
- ⚠️ **Фрустрацию** - потеря 10-15 рыб может демотивировать

Рекомендуется протестировать баланс и при необходимости уменьшить максимальный штраф.
