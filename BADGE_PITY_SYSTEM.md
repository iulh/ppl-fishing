# Система гарантированного выпадения Значка Рыболова

## Описание

Значок Рыболова (`fisherman_badge`) - легендарный предмет с очень низким шансом выпадения. Чтобы игроки не разочаровывались, реализована **система гарантированного выпадения** (pity system).

## Как это работает

### Счетчик уловов
- При каждом успешном улове **рыбы** (не мусора) увеличивается счетчик `catchesWithoutBadge`
- Счетчик отображается в левом верхнем углу экрана: 🎖️ X/50
- Прогресс сохраняется в localStorage

### Гарантированное выпадение
- После **50 уловов рыбы** без получения значка, следующий улов **гарантированно** будет Значком Рыболова
- Это происходит автоматически, независимо от редкости броска
- После получения значка:
  - Счетчик сбрасывается в 0
  - Флаг `hasBadge` устанавливается в `true`
  - Прогресс больше не отображается

### ⚠️ Штраф при срыве значка
- Если вы **зацепили Значок Рыболова**, но он **сорвался** во время подтягивания:
  - Прогресс **откатывается** на **5-15 рыб** (случайно)
  - Это добавляет риск и напряжение
  - Будьте осторожны при натяжении лески!
- Подробнее: см. `BADGE_ESCAPE_PENALTY.md`

### API уведомление
При получении значка автоматически отправляется запрос на `/api/fisherman-badge`, который уведомляет внешний API.

## Настройка порога

Порог можно изменить в файле `src/lib/fishing/constants.ts`:

```typescript
export const BADGE_PITY_THRESHOLD = 50; // Количество рыб до гарантии
```

## Технические детали

### Измененные файлы
- `src/lib/fishing/types.ts` - добавлены поля в PlayerData
- `src/lib/fishing/engine.ts` - логика pity system в pickLoot
- `src/lib/fishing/api.ts` - сохранение/загрузка прогресса
- `src/lib/fishing/renderer.ts` - отображение прогресса в HUD
- `src/components/fishing/FishingGame.tsx` - обновление счетчика

### Структура данных

```typescript
interface PlayerData {
    coins: number;
    rodLevel: number;
    catchesWithoutBadge: number; // Счетчик уловов рыбы
    hasBadge: boolean;            // Был ли получен значок
}
```

## Примечания

- Мусор (не рыба) не увеличивает счетчик
- Система работает только для первого получения значка
- Если значок выпадет случайно до порога - счетчик всё равно сбрасывается
- Прогресс синхронизируется с localStorage автоматически
